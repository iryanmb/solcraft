# Solcraft design

- `screens/pilot/` — PNGs of every pilot screen, numbered in flow order. Phone screens are 390×844 (2x); web screens are 1440 wide.
- `screens/later/` — screens for after the pilot (rooms, profile, solstice recap, glimmers). Don't build these yet.
- `source/` — the HTML mockups behind the PNGs. They need a design runtime to render, so read them for layout, copy, sizes and colors; use the PNGs to see them.

CLAUDE.md wins over anything here. Known gaps: the check-in moment and center nav button show the old QR/scan idea (build the location "I'm here" flow instead), and the phone nav shows a Rooms tab that comes after the pilot.
